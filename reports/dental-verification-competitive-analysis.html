Part 3
빈틈: 독립치과의 "Verification Hell"
경쟁자 대부분이 DSO를 쫓는 동안, 독립치과 120,000+개는 여전히 수동으로 보험을 확인하고 있다.

독립치과가 겪는 현실

  • 프론트 데스크 1~2명이 하루 15~30건 수동 확인
  • 각 건당 12~25분 — 보험사 포탈 로그인, 정보 입력, 결과 스크린샷, PMS에 수기 입력
  • Delta Dental / MetLife / Cigna / Aetna / United — 각각 다른 포탈, 다른 인터페이스
  • 내일 환자 20명 → 오늘 오후 3시간을 보험 확인에만 소비
  • 확인 안 하면 → 청구 거절 → 환자에게 추가 청구 → 분쟁 → 별점 1점

왜 기존 솔루션을 안 쓰나?

  • 가격: DentalRobot $150은 가능하지만 셋업이 복잡, Needletail은 아예 대화 불가
  • 복잡성: API 연동, 서버 설정, IT 인력 필요 — 독립치과에는 IT 담당자가 없다
  • 오버킬: Milo 같은 번들은 필요 없는 기능까지 강제 구매
  • 계약: 연 계약, 최소 인원 요구 — 소규모 치과에 맞지 않음
  • 결론: "내가 직접 하는 게 낫다"라고 판단하고 수동으로 계속함

Part 5
경쟁력 전략: 5가지 차별화
기술보다 중요한 건 포지셔닝이다. 독립치과 전용 + 극단적 쉬움 + 공정한 가격이 핵심.

1. "30분 셋업" — 극단적 쉬움

DentalRobot은 셋업에 3~5일, IT 지원 필요. 우리는:

  • Sign up → PMS 연결 → 보험사 credential 입력 → 끝. 30분 이내.
  • Open Dental 사용자: API 키 하나 입력하면 자동 연동
  • Dentrix/Eaglesoft 사용자: CSV 업로드 또는 간단 브라우저 확장
  • 셋업 가이드 비디오 3분, 라이브 채팅 온보딩 지원
  • 핵심 메시지: "IT 사람 부를 필요 없어요"

2. "Denial Prevention" — 검증이 아니라 거절 방지

단순히 "보험 있다/없다"만 확인하는 게 아니다. 거절을 사전에 막는다:

  • CDT 빈도 체크: "D0120 (구강검사) — 이 환자 마지막 검사 4개월 전, 6개월 간격 필요. 2개월 뒤에 예약하세요" 경고
  • 사전승인 알림: "D2740 (크라운) — 이 보험사 사전승인 필수. 지금 요청하시겠습니까?"
  • 연간 한도 추적: "남은 benefit $340. 이 시술 비용 $800. 환자 본인부담 $460 예상"
  • COB 자동 감지: 이중 보험 환자 자동 식별 + 1차/2차 보험 순서 확인
  • 핵심 메시지: "검증 도구가 아닙니다. 거절 방지 시스템입니다."

3. "Batch Verify" — 한 번에 내일 환자 전체

경쟁사 대부분은 건별 조회. 우리는 배치 처리:

  • 자동 배치: 매일 오후 4시, PMS에서 내일 환자 목록 자동 가져와서 일괄 검증
  • 아침 출근하면 "내일 환자 22명 검증 완료, 3건 주의 필요" 대시보드
  • 주의 필요 건만 클릭해서 확인 → 10분이면 하루 검증 끝
  • 기존: 3시간/일 → 우리: 10분/일

4. "$149/mo 올인클루시브" — 가격 투명성

경쟁사 가격 구조의 문제:

  • Milo: $200/mo에 600건 → 초과 시 추가 비용 불투명
  • DentalRobot: $150/mo Lite → 기능 제한, 풀 버전은 $300+
  • 아웃소싱: 건당 과금 → 월 비용 예측 불가 ($600~1,600)
  • 우리: $149/mo, 월 600건 포함. 초과 시 $0.25/건 (명확). 연 계약 없음.
  • 독립치과 평균 22건/일 x 22일 = 484건 → 600건 한도 내 충분
  • 핵심 메시지: "숨겨진 비용 없이, 매달 $149."

5. Open Dental "Native" 느낌 — PMS 통합 우선

PMS 선택과 출시 전략:

  • 1단계: Open Dental 전용 — 12,000+ 설치, 공개 REST API, 커뮤니티 포럼 활발
  • Open Dental 사용자에게는 "네이티브 확장" 수준의 통합 제공
  • PMS 안에서 바로 보이는 보험 상태 (iframe 또는 sidebar extension)
  • 2단계 (6개월 후): Dentrix 연동 (HL7/FHIR 브릿지)
  • 3단계: Eaglesoft (2026 구독 전환 시점에 진입 — 전환 고통 활용)
  • Open Dental 커뮤니티 → 첫 40 고객 확보 채널

  • Open Dental 사용자 Facebook 그룹 (5,000+ 멤버) 타겟
  • 전환율: 베타 → 유료 60~70% (pain point이 명확하므로)
채널 2: 치과 커뮤니티 + Reddit (10명 목표)
  • r/dentistry (180K+ 멤버), r/DentalAssistant — 보험 검증 불만 글 다수
  • Dental Town (dentaltown.com) — 치과의사 전용 포럼, 200K+ 멤버
  • Dental Office Managers Facebook 그룹 (40K+ 멤버)
  • 전략: 먼저 가치 있는 답변/자료 제공 → 신뢰 구축 → 제품 소개
  • "보험 거절 방지 체크리스트" 무료 PDF → 이메일 수집 → 제품 안내
채널 3: 콜드 아웃리치 (15명 목표)
  • Google Maps에서 "dental office" + 도시별 검색 → Open Dental 사용 치과 필터링
  • Open Dental 로고가 웹사이트에 있거나, job posting에서 "Open Dental" 언급하는 치과 타겟
  • 이메일 타겟: Office Manager (의사 아님) — 실제 검증 업무 담당자
  • "내일 환자 보험 검증에 하루 3시간 쓰시나요?" — 1줄 이메일
  • 200통 발송 → 15% 오픈 → 30통 → 5% 전환 → 15명
  • Loom 비디오 데모 첨부 (3분) → 전환율 2x
Part 7
MVP 로드맵: 12주
1인 개발자가 12주 안에 출시 가능한 범위. Phase 1은 Open Dental + 상위 5개 보험사.
Week 1-2
기반 인프라
Next.js + Supabase 셋업. 인증, 치과 프로필, 환자 관리 CRUD. Stripe 결제 연동. HIPAA BAA 서명 (Supabase Pro).
Week 3-4
EDI 270/271 연동
Availity 개발자 계정 → sandbox 테스트 → 실시간 적격성 조회 구현. 기본 결과 파싱 + DB 저장. 배치 요청 큐 구현.
Week 5-7
포탈 스크래핑 엔진
Playwright로 Delta Dental, MetLife, Cigna, Aetna, United 5대 포탈 자동화. CDT별 benefit, 빈도 제한, 대기 기간 추출. 2FA 처리 (치과 credential 사용).
Week 8-9
Open Dental 연동
REST API로 환자 목록 가져오기. 보험 검증 결과 PMS에 자동 기록. 내일 환자 자동 배치 트리거 (cron).
Week 10-11
대시보드 + 거절 방지
실시간 검증 현황 대시보드. CDT 빈도 경고, 사전승인 알림, 연간 한도 추적. 환자별 요약 리포트 (PDF 출력).
Week 12
베타 출시
Open Dental 포럼 베타 모집 (10명). 온보딩 가이드 + Loom 비디오. 2주 무료 체험 → $149/mo 전환. Voice AI는 V2에서 추가.

MVP에서 제외 (V2로 미루기)

  • Voice AI: Twilio + STT 연동은 복잡도 높음. V1은 포탈 실패 건 = 수동 확인 알림으로 대체
  • Dentrix/Eaglesoft 연동: 파트너십 또는 리버스 엔지니어링 필요. V2에서 CSV 브릿지 먼저
  • COB 자동 처리: 이중 보험 로직 복잡. V1은 감지 + 경고만, 자동 처리는 V2
  • 자동 사전승인 요청: V1은 알림만, V2에서 자동 제출
