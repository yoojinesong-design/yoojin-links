Part 2
진짜 고통: 커뮤니티에서 나온 목소리
Reddit, Facebook, YouTube, 포럼에서 수집한 솔로 디테일러의 실제 불만.

고통 #1: 노쇼 — 감정적으로 가장 큰 스트레스

"80% of clients don't stick to appointments. I drove 30 minutes, set up all my gear, and they just weren't home. No text, nothing."— Auto Geek Forum 디테일러
  • 보증금($25-100)이 해결책인 건 아는데, 요구하기가 심리적으로 어렵다
  • "단골 관계 깨질까봐" — 소개 기반 비즈니스라서 갈등 회피
  • 해결: 시스템이 자동으로 보증금을 받으면 디테일러가 "미안한 사람" 안 됨

고통 #2: 문자 지옥 — 하루 종일 폰 잡고 있기

"Text-only booking is killing your detailing business. You're detailing a car with wet hands and a customer texts asking for availability. You can't reply for 2 hours. By then they booked someone else."— CurbCar Blog
  • 작업 중 전화/문자 응답 불가 → 고객 이탈
  • Instagram DM, Facebook 메시지, 문자, 전화 — 4개 채널에서 예약 요청
  • 해결: 셀프 예약 링크 하나로 통합. "내 링크로 예약하세요" 한 줄이면 끝

고통 #3: 결제 추적 — 누가 냈고 누가 안 냈는지

  • Venmo, CashApp, Zelle, 현금 — 4가지 결제 수단이 다 따로
  • 월말에 누가 안 냈는지 파악하려면 대화 기록 뒤져야 함
  • Fleet 고객(매주 오는 차량 관리 회사)은 인보이스 필요 → 더 복잡
  • 해결: 작업 완료 → 탭 한 번 → 결제 요청 자동화

고통 #4: 비 오면 일정 폭탄

  • 모바일 디테일링은 야외 작업 → 비/눈 오면 전부 리스케줄
  • 고객 5명에게 각각 문자 보내서 일정 변경 = 30분+ 소요
  • CurbCar만 weather-aware 스케줄링 제공 중 (유일)
  • 해결: 날씨 API 연동 → 비 예보 시 자동 리스케줄 제안

고통 #5: 번아웃 — 수요 부족이 아니라 체력 고갈

  • "Physical and motivational burnout ends more solo businesses than lack of demand"
  • 하루 10시간 중 3.5-5시간이 비생산적 시간 (이동, 세팅, 행정)
  • 행정 시간만 줄여도 하루 1-2건 더 할 수 있거나, 일찍 퇴근할 수 있음
  • 해결: 예약-확인-결제 자동화로 행정 시간 최소화

  • Mobile Tech RX/QuoteIQ = 가격 맞지만 기능 불완전

  • 셀프 예약 링크 + SMS 리마인더 포함 + 보증금 자동 수금 + 탭투페이 + 재방문 자동화
Part 4
경쟁력: "5가지만 완벽히"
기능 많은 게 아니라, 솔로 디테일러의 하루를 바꾸는 5가지에 집중.
1. 셀프 예약 링크 — "내 링크로 예약하세요"
  • Instagram 프로필, Google Business, 문자에 링크 하나 공유
  • 차종 선택 → 서비스 선택 → 날짜/시간 → 보증금 결제 → 예약 완료
  • 디테일러가 작업 중 전화 안 받아도 예약이 들어옴
  • 경쟁 우위: 차량 크기별 자동 가격 (SUV vs Sedan vs Truck)
2. 보증금 자동 수금 — "시스템이 하니까 미안할 필요 없음"
  • 예약 시 $25-50 보증금 자동 결제 (Stripe)
  • 디테일러가 직접 "보증금 내세요" 말할 필요 없음 → 심리적 부담 제거
  • 노쇼 시 보증금 자동 차감, 취소 정책 자동 안내
  • 효과: 노쇼율 15-25% → 5% 이하
3. SMS 리마인더 — 비용 포함, 추가 과금 없음
  • 예약 24시간 전 + 2시간 전 자동 문자
  • SMS 비용 월 $39에 포함 (Urable은 별도 과금 — 디테일러들 불만 많음)
  • 월 100건 SMS 포함 (솔로 디테일러 평균 60-80건/월)
  • 리마인더 내용: "내일 2시 Tesla Model 3 외부세차 예약 확인. 변경: [링크]"
4. 작업 완료 → 탭 한 번 → 결제
  • 작업 끝나면 앱에서 "완료" 탭 → 고객에게 결제 링크 자동 발송
  • 잔금 = 총 비용 - 보증금, 자동 계산
  • Stripe 결제 → 다음날 입금 (Venmo/CashApp처럼 즉시는 아니지만 추적 가능)
  • 월말 수입 리포트 자동 생성 → 세금 신고용
5. 재방문 자동화 — "2개월 됐네요, 다시 예약하실래요?"
  • 고객별 마지막 서비스 날짜 추적
  • 60일/90일 후 자동 리마인더: "지난 세라믹 코팅 유지 점검 시기입니다. [예약 링크]"
  • 솔로 디테일러 매출의 60-70%가 재방문 — 이걸 자동화하면 안정 수입
  • 수동으로 하면 고객 50명 이상부터 추적 불가 → 돈이 새는 구멍
Part 5
기술: 병목 없는 스택
HIPAA도 NPI도 없다. 치과 대비 기술 장벽이 현저히 낮다.
프론트엔드
Next.js 14 + Tailwind. 예약 페이지 + 디테일러 대시보드.
백엔드/DB
Supabase — Auth, PostgreSQL, Realtime. Row Level Security로 다중 테넌트.
결제
Stripe — 보증금 수금, 잔금 결제, 구독 관리. Stripe Connect로 각 디테일러 계정 분리.
SMS
Twilio — 리마인더 발송. 건당 $0.0079. 월 100건 = $0.79/고객.
날씨 (V2)
OpenWeather API — 무료 1,000콜/일. 비 예보 시 리스케줄 제안.
배포
Vercel — 무료 시작, Pro $20/mo 시 충분.
규제
없음. HIPAA 불필요, 특수 라이선스 불필요, BAA 불필요.

치과 검증 vs 오토 디테일링 — 병목 비교

  • 보험사 포탈 스크래핑? → 없음. 외부 API 연동 자체가 없음
  • HIPAA 컴플라이언스? → 없음. 개인 건강 정보 없음
  • NPI 번호? → 없음. 누구나 바로 시작 가능
  • PMS 연동? → 없음. 우리가 곧 PMS (예약 시스템 = 우리)
  • Clearinghouse 계약? → 없음. Stripe만 있으면 됨
  • 결론: Claude로 8주 안에 MVP 가능
Part 6
MVP 로드맵: 8주
치과 12주 대비 8주. 외부 의존성이 없어서 빠르다.
Week 1-2: 예약 페이지 + 인증
  • Supabase Auth (이메일/Google 로그인)
  • 디테일러 프로필: 서비스 메뉴, 가격, 영업 시간, 서비스 지역
  • 공개 예약 페이지: 차종 → 서비스 → 날짜 → 예약
  • 커스텀 URL: detailbook.app/[상호명]
Week 3-4: 결제 + 보증금
  • Stripe Connect 온보딩 (디테일러 계정 연결)
  • 예약 시 보증금 자동 수금
  • 작업 완료 → 잔금 결제 링크 발송
  • 결제 내역 대시보드
Week 5-6: SMS 리마인더 + 대시보드
  • Twilio SMS 연동 — 24h전 + 2h전 자동 발송
  • 오늘/이번주 일정 대시보드
  • 고객 목록 + 서비스 이력
  • 모바일 최적화 (디테일러는 폰으로 사용)
Week 7-8: 재방문 자동화 + 베타 출시
  • 재방문 리마인더 자동 발송 (60일/90일)
  • Stripe 구독 ($39/mo) 연동
  • 14일 무료 체험 플로우
  • 베타 사용자 10명 모집 (Reddit + Facebook)
